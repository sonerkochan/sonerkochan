Soner Kochan — Static Portfolio
================================
Plain HTML + CSS + JavaScript. No Node, React, Astro or build step.

Deploy:
- Upload the contents of this folder to any static host.
- The entry point is index.html.
- Works from a file:// URL too, although HTTPS hosting is recommended.

Main files:
- index.html
- style.css
- script.js
- assets/

Update contact/project links directly in index.html.
